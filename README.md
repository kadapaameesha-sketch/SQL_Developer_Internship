# 📊 Social Media Analytics Backend

### 💬 Track likes. 💜 Measure engagement. 🏆 Find top posts.

A PostgreSQL project for tracking social media activity and discovering which posts get the most engagement.

---

## 🛠️ Tech Stack

![PostgreSQL](https://img.shields.io/badge/PostgreSQL-Database-4169E1?style=for-the-badge&logo=postgresql&logoColor=white)
![SQL](https://img.shields.io/badge/SQL-Analytics-orange?style=for-the-badge)

## ✨ Features

❤️ Track post likes  
💬 Store comments  
👤 Connect activity to users  
📈 Calculate engagement scores  
🏆 Rank top-performing posts  
⚙️ Automatically update like counts with triggers  
📤 Generate engagement reports  

## 🗂️ Database Tables

| Table | Description |
|---|---|
| 👤 `users` | User account details |
| 📝 `posts` | Posts created by users |
| ❤️ `likes` | Likes on posts |
| 💬 `comments` | Comments on posts |
